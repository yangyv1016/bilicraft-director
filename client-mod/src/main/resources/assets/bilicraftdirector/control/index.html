本机独立使用

本地巡游、景点队列、AI 选点与运镜均由 Mod 执行。地图来源按服务器地址与游戏世界分别保存，切换服务器或世界会清理未保存草稿。

服务端配置

管理员使用 /director map set <实际允许世界名> <Dynmap 世界名> <地图基础 URL> 设置对应关系；使用 /director map status <世界名> 查询，/director map clear <世界名> 清除。游戏连接仅下发这份外链信息。

按需更新，低负载

点击按钮后由客户端直连地图外链，不经游戏服务器下载或传输地图 JSON；页面轮询只读取本机状态。当前未启用持续热力采集。

完整退出并重新启动 Minecraft 客户端后，中控会从已保存的首选端口开始绑定。退出服务器、停止导播或刷新网页不会重新绑定端口。
