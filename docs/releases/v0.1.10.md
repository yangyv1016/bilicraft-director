# BiliCraft 导播 v0.1.10

普通场景传送落入山体后，会主动寻找安全机位并修正传送，成功后继续展示同一景点。优先读取客户端已加载区块的真实高度图，保持可配置的离地高度，减少直播入镜等待；不使用Dynmap固定标点Y推断地形。新增最大俯仰角和陡角自动拉远，避免抬升后镜头过陡。

| 安装包/模块 | 版本 | 升级要求 |
| --- | --- | --- |
| Fabric客户端 | 0.1.10 | 退出客户端后替换旧Mod JAR，保留配置 |
| Paper服务端 | 0.1.3 | 本次未修改，已安装此版无需替换 |
| 内嵌Java协议模块 | 0.1.3 | 已包含在安装包中，不单独安装 |
| 通信协议 | v7 | 客户端0.1.7～0.1.10兼容服务端0.1.3；与旧v6不兼容 |

Minecraft 1.21.11、Java 21；客户端使用Fabric，服务端使用Paper。

## 机位修正

- 先尝试12个同高角度，再读取已加载区块现有`WORLD_SURFACE`高度图，验证地表上方至少10格、且满足当前最低离地设置的机位（默认16格）。查询不主动加载区块，也不重建缺失高度图；初次相邻区块未齐时，后续每250毫秒优先重试快路径。
- 快路径无法通过时，分帧继续搜索同高及更高机位，包含世界最高合法Y；每250毫秒至多16个候选，每个查询实例仍为8192扫描预算。跨帧保留进度，避免反复查询早期候选却到不了山顶。
- 空间、近景8格视线、世界边界、高度和排除区均须通过，UNKNOWN不视为安全。搜索最多5秒、最多6次已确认候选的本人原生TP；已发出的修正保留到达/加载确认时间。
- 搜索与入镜期间不扣场景时长；实际到位后继续原景点和队列，临时抬升不覆盖保存的绝对Y。停止、跳过、换目标和连接变化会清除旧搜索。
- 近距FLY继续使用安全局部路径；服务器挂机点严格锁定，玩家接近仍服从服务端预告、15秒准备期限及96格检查。真正无可用机位时才回退或跳过。

## 离地高度与构图

- WebUI实时区和配置页提供**场景最低离地高度**：默认16格，0～128格，0关闭。以相机脚下真实地形为依据，机位目标不足时临时抬升；保留用户绝对Y偏好，不把地图标点固定Y当地面。平滑爬升仍经过真实碰撞检查，实际接近目标时有约0.1格内收敛误差。
- **最大俯仰角**默认45°，可设置5～80°，同时限制向上与向下；普通入镜与持续运镜均执行，固定服务器挂机点保持管理员原姿态。
- **陡角自动拉远**默认开启，可实时开关。提前5°开始向外调整构图，场景不超过256格，玩家跟随不超过24格；不改变保存的距离，不额外传送，继续使用局部避障与原速度平滑。
- 调整俯仰上限、自动拉远或速度不清除已有临时抬升；修改高度等构图参数时从实际安全机位重新衔接，避免深山修正后再次卡住。
