## 服务器挂机点

- 每个世界共用一个固定机位，服务端按世界UUID保存在`plugins/BiliCraftDirector/idle-points.yml`，服务器重启和世界改名后保留。
- `/director idle set`保存当前位置及注视方向；`/director idle set <x> <y> <z> <yaw> <pitch>`设置绝对机位；`/director idle info`查看，`/director idle clear`清除当前世界的点位。
- 管理权限为`bilicraftdirector.idle.manage`，默认OP。客户端`/directoridle set [x y z yaw pitch]`、`info`、`clear`保留为本人原生命令上传入口，由服务端校验并保存，成功后同步给当前世界的授权导播；其他导播仍需`bilicraftdirector.data.read`。
- 挂机点进入游戏目标库、WebUI和自动/AI候选，按普通场景时长结束（30～600秒，默认120秒），遵守巡游世界资格及本次登录已播规则，允许手动重播。
- 使用本人`minecraft:tp`权限切入保存位置和方向，到达并加载后固定机位、完全不运镜。世界边界、高度、排除区继续生效；修改或清除当前点会停止播出，旧待播姿态不会转为普通环绕。
- 客户端失联、断线或切世界清除内存机位，握手、心跳、切世界及修改时由服务端重新同步。此前未发布的本机挂机点文件不再读取或自动上传，需重新执行set。

## 地图筛选与转场

- 只提取Dynmap可见标题，移除CSS与创建者等隐藏提示，继续清理HTML及Minecraft颜色/样式码。
- 屏蔽`newhoroburgh.market_g7`等内部命名、明确铁路里程/信号机/道岔/控制节点和系统世界边界候选；保留车站建筑、正常英文名称、星门及正常公会/领地。旧地图缓存也过滤可识别的内部标识和CSS残留。
- 保留同名同类型128格内去重规则和全部区域几何，不新增地理禁拍区。本次真实Dynmap数据验证：924项输入最终保留623项候选，屏蔽153项、去重148项，保留360个区域多边形；数据源变化后数量可能不同。
- 起镜先淡出，在遮罩内直接设置yaw/pitch及上一帧角度，构图就绪后淡入，预调整不平滑旋转。远处传送保持遮罩，近距飞行校准朝向后正常显示，准备和入镜期间不消耗场景时长。
- 协议升级保留本地v4/v5场景缓存和v5世界政策缓存的明确迁移，旧网络包头仍拒绝。
