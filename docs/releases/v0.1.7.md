# BiliCraft 导播 v0.1.7

玩家素材现在读取当前Paper后端的完整可公开在线名单，同世界远处玩家可在15秒预告后获准接近，实际到位和安全检查通过后才开始跟随。修复临时未知地形使导播显示运行、补队却永久暂停的问题，并让中控明确区分“仅手动”和“地形保护”。

Minecraft 1.21.11、Java 21；客户端使用Fabric，服务端使用Paper。停服/退出客户端后移除旧双端JAR再替换，保留现有配置、世界名单、挂机点及玩家隐私数据。本地旧v4/v5/v6无玩家场景缓存和v5/v6世界规则缓存按明确未变布局迁移；这不意味着旧网络消息仍兼容。

## 全服玩家与授权接近

- 来源是当前Paper后端全部可公开其他在线玩家；排除本人、canSee隐藏、隐身及vanished，不按摄影机距离或已加载区块过滤。Paper原版观察者自动带隐身标志，通常也不公开。不汇总代理下其他后端。
- 素材只有UUID、名字、世界和AVAILABLE/OTHER_WORLD/IDLE/SPECTATOR/UNAVAILABLE状态，没有玩家坐标或轨迹；跨世界只显示状态，不自动传送或观察。
- 完整响应按请求ID分页，每页最多32玩家或32场景，最多4096玩家、256总页，超限明确拒绝，不截断名单。客户端收齐和校验后整体应用，旧连接/世界/请求的分页不会混入。
- 首次Hello授权自动刷新一次；导播运行且自动补足开启、未暂停和无业务占用时，最多每60秒刷新，不因地图景点已经充足而跳过。
- NOTICE预告15秒后重新校验，再进入最多15秒APPROACHING并仅向该摄影机发送会话ID和当前目标姿态。必要时本人数字坐标tp接近；真实区块、玩家实体、机位和视线安全后发Ready。服务器重新核对实际同世界距离≤96格、权限与隐私，FOLLOWING后才开始3～8分钟计时。
- 拒绝、长期黑名单、冷却、10秒无动作、至少32格传送、离线、跨世界和排除区等保护继续有效。旧会话Ready不影响新会话，TP权限不足或接近超时结束观察。

完整边界见[全服玩家名单与授权观察](../full-player-roster.md)。

## 补队、巡游状态和地形恢复

暂时UNKNOWN触发机位保护后，世界就绪时每250毫秒复查当前占用，仅CLEAR才解除暂停并继续排播/补队；BLOCKED或UNKNOWN继续保持遮罩。解锁仍经过正常revealShot构图校准后淡入，不直接暴露未准备的镜头，手动停止不会被恢复检查重新启动。

WebUI显示“地形保护”及恢复说明；世界未获自动巡游资格时显示“仅手动”，保留手动选点和入队。管理员仍需通过`/director worlds list`核对实际世界，再用`/director worlds add <实际已加载世界名>`开启；本机中控不会绕过WorldPolicy、隐私或Minecraft命令权限。

## 一并交付的0.1.6开发内容

- 普通镜头保持用户保存高度，优先同高机位/水平绕行，必要时有界临时抬升，基础路线持续安全后缓慢回落；检查实际占用、扫掠路径、惯性下一步和视线。UNKNOWN不当作安全，不将近距FLY升级为TP。服务器挂机点仍严格锁定位姿。
- Mod初始化即异步预取默认Hyperion/Paralon地图，不等待进服或打开中控；进入匹配世界且资源包/世界就绪后安全应用，缓存和同源在途请求复用，不持续轮询地图。
- 0.1.6历史实测的产物摘要与范围保留在[地形避障说明](../terrain-avoidance.md)，不自动算作本版最终JAR实测。
