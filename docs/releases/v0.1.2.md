# BiliCraft 导播 v0.1.2

本次更新客户端，服务端代码与通信协议保持不变。

| 安装包 | 版本 | 更新建议 |
|---|---|---|
| Fabric客户端 | 0.1.2 | 替换原客户端Mod |
| Paper服务端 | 0.1.1 | 已安装0.1.1无需替换 |
| 通信协议 | v5 | 客户端0.1.2与服务端0.1.1兼容 |

从本次起，发布标签与两端安装包版本独立管理，服务端不再因客户端更新而自动升版。

## 修改

- 左上角显示当前排播目标名称，随目标切换更新；停止或无目标时隐藏。
- 修正Dynmap标签中的`&1`等颜色/样式码，清理格式码后统一白字显示。
- Dynmap候选按同类型、同名、水平距离不超过128格筛除重复，保留远处同名地点、代表点原始坐标与全部区域多边形。真实数据验证由924项筛为777项，合并147项。
- 每次登录维护仅内存的已播名单，自动补点和AI补点跳过已播目标，从剩余候选随机抽样，保留场景约80%/玩家约20%的倾向。AI候选不再固定取名称排序靠前的12项。
- 场景到达并开始展示、玩家获准且实际入镜后才计为已播；到达失败、拒绝预告不计入。停止再启动、切换世界保留名单，断线/重新登录清空；允许手动重播，候选耗尽不自动重置名单。

## 验证与附件

- 客户端181项、协议39项、服务端52项，共272项测试；构建及测试报告见该标签对应的GitHub Actions运行。
- 发布附件为标签构建通过后生成的`bilicraft-director-client-0.1.2.jar`、`bilicraft-director-server-0.1.1.jar`及`SHA256SUMS.txt`。
- 已完成真实Dynmap HTTP验证与本次修改范围的规范检查；未进行真实游戏HUD切换、播出/重新登录和双端联机验证，没有发起付费AI调用。

Minecraft仍要求1.21.11、Java21；客户端使用Fabric，服务端插件使用Paper。升级客户端前请退出游戏。
