# BiliCraft 导播 v0.1.11

修正持续运镜的离地高度：此前自动拉远绕出高地后，规划器开始降低临时抬升，绕回时实际镜头可能贴近地表。本版在最终惯性移动步骤检查真实地表，进入高地前先原地平滑抬升，离开高处前不提前下降；未知地表停止等待。0.1.10已撤回为草稿，请安装本版。

| 安装包/模块 | 版本 | 升级要求 |
| --- | --- | --- |
| Fabric客户端 | 0.1.11 | 退出客户端后替换旧Mod JAR，保留配置 |
| Paper服务端 | 0.1.3 | 本次未修改，已安装此版无需替换 |
| 内嵌Java协议模块 | 0.1.3 | 已包含在安装包中，不单独安装 |
| 通信协议 | v7 | 客户端0.1.7～0.1.11兼容服务端0.1.3；与旧v6不兼容 |

Minecraft 1.21.11、Java 21；客户端使用Fabric，服务端使用Paper。

## 离地高度与构图

- 最低离地高度默认16格，实时区和配置页可调0～128格，0关闭。依据已加载区块现有`WORLD_SURFACE`高度图的最高非空气方块坐标，不使用Dynmap固定Y，也不触发区块加载或缺失高度图重建。
- 最终移动步骤检查当前、前方及斜向两侧地表，覆盖原版单轴微速度清零的情况。提前抬升和下降限位仍受原速度、物理路径、世界边界、高度及排除区检查约束；不改写保存的绝对Y。
- 最大俯仰默认45°，可调5～80°，上下均限幅。陡角自动拉远默认开启，提前5°调整，场景≤256格、玩家≤24格，不修改保存距离或额外传送。
- 玩家继续使用独立跟拍高度；服务器挂机点仍严格锁定保存位姿。未运行导播时保持正常客户端操作。

## 山体落点修正

保留0.1.10引入的快速修正：远处传送后在起镜遮罩内先尝试同高角度，随后优先验证真实高度图上方的机位；必要时跨帧搜索更高候选，最多5秒搜索和6次已确认候选的本人原生TP。已发出的修正保留到达/加载等待，搜索及入镜不扣场景时长。成功后继续同一景点；停止、跳过或连接变化清除旧搜索。近距FLY不升级TP，隐私、名单和排除区规则保持有效。

- 服务端和协议代码未修改；最终云端JAR的第二次游戏启动、正式BiliCraft长期直播及极端网络延迟不在本轮验证范围。
